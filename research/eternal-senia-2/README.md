# Bàn giao tham khảo Eternal Senia 2

Đọc [START_HERE.md](START_HERE.md) trước. Đây là kết quả nghiên cứu tĩnh từ gói
người dùng cung cấp, để thiết kế game **cùng thể loại bằng nội dung và mã riêng**.
Không phải mã nguồn Unity gốc, project import được, hoặc giấy phép dùng asset.

| Tài liệu | Dùng khi |
| --- | --- |
| [START_HERE](START_HERE.md) | Chatbot mới bắt đầu, cần biết đã làm gì và chưa biết gì |
| [EVIDENCE](EVIDENCE.md) | Phân biệt đã xác minh, suy luận và đề xuất |
| [ARCHITECTURE](ARCHITECTURE.md) | Hiểu cấu trúc hệ thống và vòng chơi |
| [DATA_MODEL](DATA_MODEL.md) | Hiểu schema, quan hệ bảng và giới hạn công thức |
| [ANIMATION](ANIMATION.md) | Thiết kế frame, pivot, timeline và mốc hiệu ứng |
| [ASSET_MAP](ASSET_MAP.md) | Tìm tài nguyên trong dump, tránh tải lại toàn bộ |
| [BUILD_BLUEPRINT](BUILD_BLUEPRINT.md) | Xây bản Godot mới theo từng mốc |
| [REPRODUCE](REPRODUCE.md) | Kiểm chứng hoặc chạy lại việc phân tích |
| [PRIVACY_AND_RIGHTS](PRIVACY_AND_RIGHTS.md) | Biết dữ liệu nào không được đưa vào game/báo cáo |
| [examples](examples/) | Một bộ dữ liệu mẫu mới, validator và mô phỏng đơn giản |
| [catalogs](catalogs/) | 8 chỉ mục JSON đã trích xuất, không cần chạy lại dumper |

Trạng thái kiểm chứng: 46 tài sản/bảng JSON đọc được; 33 lớp cốt lõi được lập
chỉ mục khai báo; 3 clip kiểm tra sâu. Danh mục Sprite có 3.178 bản ghi quét,
không phải 3.178 ảnh duy nhất. 4.315 body MonoBehaviour chưa giải mã thành kiểu.
Không dùng con số phần trăm trong chat làm thước đo hoàn thành.
